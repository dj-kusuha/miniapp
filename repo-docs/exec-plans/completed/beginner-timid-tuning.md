# Title

初心者段の臆病化（ブロット回避バイアス・キューブのテイクマージン追加）

## Status

completed

## Background

2026-11-09 の体感調整（PR #65、σ0.20 / maxLoss 1.00 / ダブルマージン /
ベアオフDB不使用）を公開したあとの 2026-11-10 のテストプレイでも、初心者が
「まだ初心者というほどではない」という体感だった。駒捌きは堅実で、キューブは
マッチポイントでも不用意にダブルし、点数はテイクの連続で膨らんだ。

オーナーの指摘：「初心者はブロットを残すのを極端に嫌うはず」。実際、400 局面の
内部測定（levels と同じ集め方）では「安全な代替手があるのにブロットを残す」
割合が最善手 28.4% に対し現行初心者は 42.3% あり、ノイズは方向性を持たない
ためブロット回避の性格が付いていなかった。

## Scope

- 初心者だけ着手スコアにブロット回避バイアスを入れる：接触局面で、相手の
  直接射程（1〜6）またはバー再入場で打たれ得る自分のブロット 1 個につき
  **0.20** 点を引く（`blotPenalty`、既定 0・初心者だけ）
- 初心者だけ σ 0.20 → **0.25**、maxLoss 1.00 → **1.25**
- 初心者のダブルマージンを増やす（マネー 0.15 → **0.25** / マッチ 0.03 → **0.05** MWC）
- テイク判断にも初心者だけのマージンを新設する（`takeMargin` マネー **0.10** 点 /
  `matchTakeMargin` マッチ **0.02** MWC、既定 0）。前回計画の Non-Scope
  「テイク／ドロップ判断へのマージン追加（別途測る）」の実施分
- 段テストにブロット回避の振る舞いとテイクマージンの境界を追加する
- 仕様（product-specs/backgammon.md）と agent.js の段コメントへ記録する

## Non-Scope

- カジュアル以上の段の値の変更
- モデル重み・推論器・探索そのものの変更
- engine（Python）側の段定義の変更
- テイクマージンのマネー非 search 経路（Janowski / 定数式）への適用
  （実戦の既定は search 方式。その経路ではマージン 0 と同じになる）

## Acceptance Criteria

- `tests/backgammon/levels.mjs` が通る（ブロット回避の集計とテイク境界を含む）
- `tests/backgammon/run.mjs` が通り、他段とパリティに影響しない
- 初心者以外の段の Agent 設定が従来と同一（罰・マージン 0）

## Steps

1. 着手選択・キューブ判断の実経路と、ブロット罰の効果を局所測定する
2. 実行計画を作成する（本ファイル）
3. agent.js に `exposedBlotCount` / `blotPenalty` / テイクマージンを実装する
4. テストを追加し、全テストを実行する
5. 結果を仕様と計画へ反映する

## Decision Log

- 2026-11-10: 罰の大きさは局所測定で選んだ。罰 0.10 / 0.15 / 0.20 で
  「ブロットを残す選択」は 26.0% / 18.8% / 13.5%（現行初心者 42.3%、
  最善手 28.4%）。B案（もっと臆病に）として 0.20 を採用。なお罰を入れると
  平均損失はむしろ下がる（48.5 → 42.1 mEMG）ため、これは弱さではなく
  性格付けの軸であり、弱さは σ / maxLoss 側で調整する。
- 2026-11-10: ブロット罰はノイズと同じく盤面から決定的に計算し、着手
  スコアへ線形に引く。2 段階の絞り込み（まずブロット最小の手に限る）は
  「絶対にブロットを残さない」不自然さが出るため採らない。

## Result

初心者だけ、着手スコアへブロット回避バイアス（`blotPenalty` 0.20、既定 0 の
専用つまみを新設し `exposedBlotCount` で決定的に数える）を入れ、σ 0.20 →
0.25 / maxLoss 1.00 → 1.25、ダブルマージンをマネー 0.25 / マッチ 0.05 MWC
へ拡大し、テイクマージン（`takeMargin` 0.10 / `matchTakeMargin` 0.02 MWC、
既定 0）を新設した。他段は無変更。

`levels.mjs` の 400 局面では初心者の最善一致 33.8% / 平均損失 54.7 mEMG
（前回調整後 32.5% / 62.8 mEMG）。平均損失が下がったのは、ブロット罰が
ノイズのミスの多くを打ち消すためで、狙いどおり「弱さより性格」の変化。
「安全な代替手があるのにブロットを残す」選択は 208 局面中 41（19.7%）で、
最善手の 59（28.4%）を下回った（バイアス導入前は 42.3% 相当）。
gnubg の ER 再測定は未実施（docker が必要）。
